# README.md
This directory contains interacter Jupyter notebooks in the [./notebooks/](notebooks) directory, with key output in [./results/pooling_math/2026-01-12_repooling_math.csv](./results/pooling_math/2026-01-12_repooling_math.csv) which dictates how much volume of each strain to include in a balanced virus library pool. See those notebooks' descriptions and inline comments for details.

First, build and activate the conda environment using below, then run individual notebooks interactively. 
```
conda env create -f environment.yml
conda activate library_pooling
```

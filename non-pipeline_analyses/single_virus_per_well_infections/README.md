# Analyze single virus-per well infections to look for contamination

This directory analyzes single-virus per well infections to look for contamination.

[notebook.py](notebook.py) is a notebook Caroline wrote that analyzes fraction of counts by different barcodes.

[notebook_by_barcode_status.py](notebook_by_barcode_status.py) is a notebook Jesse built off Caroline's notebook that also classifies barcodes by if they are what is expected in well, from an adjacent well, a distant well, or neither.
